功能與用法Features and usage

「網頁」表示可以在上方示範操作；「本機」表示要在自己的電腦執行下面的指令。"Web" means you can try it in the demo above. "Local" means run the command on your own computer.

功能Feature說明What it does在哪裡用Where
單一標的回測Single-asset backtest SMA 交叉、唐奇安通道、動量三種策略，扣除手續費、證交稅與滑價後計算績效。SMA crossover, Donchian channel and momentum, with costs deducted. Web Local
python -m quant_platform.cli --symbol 2330 --strategy sma --fast 20 --slow 60
停損與風控Stop loss and risk limits 停損、單日虧損上限、最大回撤停止。停損可在示範中試用，其餘兩項在本機設定。Stop loss, daily loss limit and max-drawdown halt. Stop loss is in the demo; the other two are local. Web Local
--stop-loss 0.08 --daily-loss-limit 0.03 --max-drawdown-halt 0.2
滾動前進驗證Walk-forward validation 參數只在訓練區間選擇，樣本外區間才評估，用來檢查是否過度擬合。Parameters are chosen on training windows only, then tested out of sample. Local
python -m quant_platform.validate_cli --csv prices.csv --fast 5,10,20 --slow 40,60,120
多標的投資組合Multi-asset portfolio 等權或訊號加權，可設定再平衡頻率與單一標的上限，超出上限的部分以現金持有。Equal or signal weights, with rebalancing frequency and a per-asset cap. Excess goes to cash. Local
python -m quant_platform.portfolio_cli --csv 2330=a.csv --csv 2317=b.csv --max-weight 0.25
績效指標Performance metrics 報酬、年化報酬、最大回撤、Sharpe、Sortino、Calmar、獲利因子，並附 Sharpe 的 95% bootstrap 區間。Returns, CAGR, max drawdown, Sharpe, Sortino, Calmar, profit factor, and a 95% bootstrap interval for Sharpe. Web Local
示範顯示部分指標；完整指標在本機輸出。The demo shows some metrics; the full set is local.
紙上交易Paper trading 只模擬下單，帳戶狀態以 JSON 檔保存，不連接任何券商。Simulated orders only. Account state is saved to a JSON file. No broker connection. Local
python -m quant_platform.paper_cli --symbol 2330.TW --state account.json --capital 1000000
資料來源Data sources 可從 Yahoo 或 TWSE 取得歷史價格，也能匯入自己的 CSV 檔（需要 date 與 close 欄位）。Historical prices from Yahoo or TWSE, or your own CSV with date and close columns. Local
--symbol 2330 --source twse / --csv my.csv
自訂市場設定Custom market profiles 用 JSON 定義交易日數、手續費與證交稅，不限於台股預設值。Define trading days, fees and sell tax in a JSON file. Local
--market-file my_market.json
HTML 報告HTML report 輸出單一 HTML 檔，不需要伺服器即可打開。範例見下方。Exports one HTML file that opens without a server. Samples are below. Local
--report report.html
雙語輸出Bilingual output 命令列與報告都支援繁體中文與英文。The command line and reports support Traditional Chinese and English. Local
--lang en / --lang zh-TW
帳號與稽核Accounts and audit log 管理員與一般成員兩種角色，密碼以 PBKDF2 雜湊儲存，多次失敗會暫時鎖定；建立帳號與登入事件會寫入稽核紀錄。Admin and member roles. Passwords are stored as PBKDF2 hashes with temporary lockout after repeated failures. Account and sign-in events go to the audit log. Local
python -m quant_platform.accounts_cli --db accounts.db --workspace ws create --email you@example.com
風險平價與因子檢驗Risk parity and factor checks 依風險貢獻計算權重（Ledoit-Wolf 收縮估計），以及動量因子的 IC 檢驗。Risk-parity weights with Ledoit-Wolf shrinkage, and momentum factor IC checks. Local
python -m quant_platform.risk_parity_cli --csv A=a.csv --csv B=b.csv
