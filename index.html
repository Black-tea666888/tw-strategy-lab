A free, open-source backtesting and paper-trading tool for Taiwan stocks. Built for individual investors and students who want to test strategies.

This site gives no investment advice, stock recommendations or return promises. All examples use simulated data, not real prices. Past backtest results do not predict future performance. The tool places no orders and holds no funds.

功能

  • 單一標的回測：SMA 交叉、唐奇安通道、動量策略，含交易成本（手續費、證交稅、滑價）。
  • 滾動前進驗證：參數只在訓練區間選擇，樣本外區間才評估。
  • 多標的投資組合：等權或訊號加權，可設定再平衡頻率與單一標的上限。
  • 風險控管：停損、單日虧損上限、最大回撤停止。
  • 績效指標：Sharpe、Sortino、Calmar。
  • 紙上交易：只模擬下單，記錄於 JSON 與 HTML 日報。

Features

  • Single-asset backtests: SMA crossover, Donchian channel, momentum, with trading costs (commission, sell tax, slippage).
  • Walk-forward validation: parameters are chosen on training windows only, and tested out of sample.
  • Multi-asset portfolios: equal or signal weights, configurable rebalancing and per-asset caps.
  • Risk controls: stop loss, daily loss limit, maximum drawdown halt.
  • Metrics: Sharpe, Sortino, Calmar.
  • Paper trading: simulated orders only, logged to JSON and an HTML daily summary.
