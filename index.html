功能

01

單一標的回測

SMA 交叉、唐奇安通道、動量三種策略，扣除手續費、證交稅與滑價後計算績效。

02

滾動前進驗證

參數只在訓練區間選擇，樣本外區間才評估，用來檢查策略是否過度擬合。

03

多標的投資組合

等權或訊號加權，可設定再平衡頻率與單一標的上限，剩餘資金以現金持有。

04

風險控管

停損、單日虧損上限與最大回撤停止，觸發後不再持有該部位。

05

績效指標

Sharpe、Sortino、Calmar，並附上年化報酬、回撤與月報酬表。

06

紙上交易

只模擬下單，狀態存為 JSON，每日產生 HTML 摘要。不連接任何券商。

07

資料來源

可從 Yahoo 或 TWSE 取得歷史價格，也能匯入自己整理的 CSV 檔。

08

自訂市場設定

用 JSON 定義交易日數、手續費與證交稅，不限於台股預設值。

09

離線 HTML 報告

每次回測可輸出單一 HTML 檔，不需要伺服器或外部資源即可打開。

10

雙語介面

網頁與命令列都支援繁體中文與英文，報告內容也依語言輸出。

11

選用登入與權限

管理員與一般成員兩種角色，密碼以 PBKDF2 雜湊儲存，多次失敗會暫時鎖定。

12

稽核紀錄

帳號建立、權限變更與登入事件都會寫入紀錄，方便追查。

Features

01

Single-asset backtests

SMA crossover, Donchian channel and momentum, with commission, sell tax and slippage deducted.

02

Walk-forward validation

Parameters are chosen on training windows only, then tested out of sample to check for overfitting.

03

Multi-asset portfolios

Equal or signal weights, with configurable rebalancing and per-asset caps. Unallocated cash is held.

04

Risk controls

Stop loss, daily loss limit and maximum drawdown halt. Once triggered, the position is no longer held.

05

Performance metrics

Sharpe, Sortino and Calmar, with CAGR, drawdown and a monthly return table.

06

Paper trading

Simulated orders only. State is saved as JSON and a daily HTML summary is produced. No broker connection.

07

Data sources

Fetch historical prices from Yahoo or TWSE, or import your own CSV file.

08

Custom market profiles

Define trading days, fees and sell tax in a JSON file. Not limited to the Taiwan defaults.

09

Offline HTML reports

Each backtest can export a single HTML file that opens without a server or external resources.

10

Bilingual interface

The web app and command line support Traditional Chinese and English, and reports follow the chosen language.

11

Optional sign-in and roles

Admin and member roles. Passwords are stored as PBKDF2 hashes, and repeated failed logins lock the account temporarily.

12

Audit log

Account creation, role changes and sign-in events are recorded for review.
